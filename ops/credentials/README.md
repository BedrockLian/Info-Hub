# SSH 接入归档

`ssh-config.zip.gpg` 是用户提供的 SSH 配置压缩包的 GnuPG AES-256 加密归档，已验证解密后与原压缩包逐字节一致。仓库不包含明文私钥或解密口令。

解密口令由所有者保存到仓库外的密码管理器。原上传文件及当前执行凭据仅用于获授权的服务器部署，不进入应用镜像、静态资源或发布包。

在可信机器还原：

```bash
gpg --output ssh-config.zip --decrypt ops/credentials/ssh-config.zip.gpg
```

按提示输入独立口令，不把它写在命令行、URL 或 Git 中。解压到仅所有者可访问的位置，私钥权限设为 600，目录设为 700。使用严格主机校验，并与交接文档的主机指纹核对。

目标服务器为 `43.128.10.41:22`，用户 `root`；不得影响该服务器上的其他站点。

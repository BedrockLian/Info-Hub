后台「设置」顶部的「AI模块总开关」控制新的模型请求，适用于文章预筛、评分、理解、摘要、抽取、翻译、事件归组／综述及日报AI选题／导语。2026-10-17 20:02已经用户确认发布，并按要求关闭云端AI；之后从后台操作无需重启。

- 关闭：API将偏好存入`settings.runtime.ai`，worker和模型回执链路读取同一状态，不使用进程内状态缓存。Pi模板队列中的请求在派发后、计费预留前重新检查；回执提交后、发送前再检查一次。
- 收尾：已发出的请求继续保存结果及付费回执，不主动中断或抹去费用。暂停期间允许复用已经接收的有效回执，不额外购买答案。
- 等待：文章分析保留失败次数和手动重跑标识；事件和日报AI增强保留任务数据，约每60秒检查后续执行条件，暂停不消耗失败重试。翻译扫描暂停，不记录失败尝试。
- 恢复：开启后等待中的任务自动继续，仍受原有预算、次数、谷价窗口、模型配置与各模块开关限制。没有启用的模块不会因此开启；不承诺积压立即处理完毕。

采集、正文抓取、阅读、已有发布内容、每五分钟的规则关注榜和日报基础版继续工作。暂停不删除文章、任务或回执，不改来源启停和预算数值，也不把人为暂停报成文章处理故障。已经存在的未知付费结果仍按原恢复规则处理。

## 权限与接口

- `GET /api/admin/settings`新增`ai`：`enabled`为管理偏好，`deploymentEnabled`为部署安全阀，`effectiveEnabled`为两者同时允许，`updatedAt`为最近偏好修改时间。
- `PUT /api/admin/settings/ai`接收`{"enabled":false}`或`{"enabled":true}`，返回上述状态。需要管理员会话及CSRF，拒绝用字符串代替布尔值；只读Bearer令牌不能修改。
- 使用绝对状态写入，重复提交相同状态不会反复切换或追加无意义审计。实际变更与`settings.ai`审计在同一事务提交。
- 未保存偏好时按开启处理，保持升级前行为。运行是否允许仍取决于`MODEL_CALLS_ENABLED`；值为false时界面显示「部署已禁用」，不能从网页打开外部调用。

私有站的模型调用继续由Pi Agent Core／Pi AI及原付费回执链路执行。开关不进入提示词、输入身份或缓存键，暂停／恢复不会使有效回执或DeepSeek固定提示前缀失效。

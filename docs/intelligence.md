# 近期关注榜与情报日报

本版面服务国际时事、外媒对华、科技、游戏与公共事务的个人阅读。保留本站精选门槛、信源权限、私有访问、模型凭据和预算；以下规则只决定已审核材料如何编排。

## 近期值得关注

每五分钟从当前可读、非回填、报道时间位于过去48小时的情报中取最多10件独立事件。排序依次采用精选资格、已有编辑评分、最新报道时间、独立来源数和稳定事件ID。无评分保留未知；不额外调用模型评分。重要单来源事件可入榜，明确标记“单一来源”。

同一事件优先以精选报道为代表，每领域先取至多3席，再用其余合格事件补位。来源的 `signal_group_id` 作为独立性分组，重复报道不增加独立来源数。新榜单不显示未经校准的热度指数或趋势。既有事件历史图表保留原有数据，不当作本次关注排序的依据。

网站接口新增 `category`、`selected`、`score`、`reasons`；`status` 区分 `ready`、`empty`、`processing`、`stale`。最近榜单超过15分钟未更新即提示滞后。读取时复核新榜条目的当前权限，撤稿不等下一次计算才隐藏。

## 日报时段与编排

北京时间08:00首版，起点固定为前日08:00；日内每小时检查新资料，累计至当日22:00定稿。后续补入材料可产生内容修订。无材料变化时只推进覆盖终点和定稿状态，不重复生成正文或递增内容修订号。

先按规则保存可读基础版：精选重点最多5件（可用重点足够时至少3件），其余材料每领域最多2条简讯，总计最多15件。内容少时少收；阅读时长按实际文字量估算，不虚写固定分钟数。重点和简讯在页面上分开，保留分类、出处与原文链接。

同一事件只保留一个条目；较新的不同事实附在原条目的“最新进展”中，附自己的来源。每期记录已覆盖事实，抑制下一期重叠区间内已报道的事实，同一长期事件的新事实仍可进入下一期。当前发布权限决定能否收录，报道时间决定所属区间；分析或审核晚完成不会因窗口内的历史权限判断而永久漏收。

每小时补刊检查会按日期顺序复核最近7天的新版日报，接收定稿后的迟到材料并标记“迟到补充”，再更新当期，避免在相邻期重复出现。旧版无输入哈希的历史日报保留原样；更早期次可由明确指定日期的后台重建操作修订，不批量改写历史。每期使用 PostgreSQL 会话级 advisory lock 防止并发重复生成。

## Pi 与缓存

基础版保存后，独立 worker 队列 `reports.enrich-daily` 读取该期最新快照。先执行 `report_curate`（low，只返回候选ID），再执行 `report_lead`（none，返回头条ID、标题与跨领域导语）。两步都经过现有 Pi Agent Core、Pi AI、付费回执、次数/金额/谷价安全阀和模板队列，不引入读者打开页面触发的模型调用。

候选最多40条，稳定排序，摘要限长。公共编辑指令、场景规则和JSON结构固定在材料之前，时钟、刷新次数不放入固定前缀。输入哈希包含材料及版本、模型配置、提示词版本、参数与输出结构；材料不变时跳过，已校验回执可复用。队列只携带期次日期，不保存陈旧正文；执行前、第二次调用前、保存前均复核最新哈希，旧任务不能覆盖新版日报。

重点ID必须属于已精选候选；简讯ID必须属于合格候选，拒绝重复ID、重复事件、越界引用和超额条目。导语携带明确的 `leadItemId`，配图和链接不再靠标题相似度猜测。失败、预算暂停、超时或不合格响应保留基础版；预算等待走既有延后机制，普通错误遵守队列的3次重试限制。

后台“日报、周报、月报”能力包含新选题场景，继续分别显示调用、费用、原生输入缓存和有效结果复用。原生缓存明细缺失或不一致时显示未知，不从复用率推算输入缓存命中率。测试证明请求结构和复用边界，不证明生产缓存已有提升；发布后用自然任务的真实回执观察。

网站日报接口新增 `editionStatus`、`enrichmentStatus`、`leadItemId`，引用新增 `editionRole`、`updateType`、`latestUpdate`。旧字段、路径与旧期次仍可读取。迁移0044仅扩展日报生成来源，允许 `origin=rule`；不更改信源或预算。

## 发布与回退

验收记录见 [本次验证记录](intelligence-validation.md)。生产发布按工作约定单独确认；发布前备份数据库、当前版本和受限访问的运行环境文件，保留原镜像和版本目录。

使用本地已构建网页产物，复用现有依赖构建轻量覆盖镜像，避免在2GB服务器执行高内存网页构建。部署只切换本站 API、worker、web；不修改共享Nginx或其他站点。迁移0044向后兼容，失败时恢复原应用镜像，保留数据库及新迁移，不自动恢复整库或删除卷。

上线后仅计算当前关注榜、更新当期日报；不执行历史批量重建。再次核对私有访问、后台新任务统计、发布前来源快照及现有预算，不硬编码来源数量。最初发布时为50源；最新来源已按确认方案调整，见[当前状态](status.md)。真实模型调用继续由原有安全阀安排，不为验收绕过峰时限制。
